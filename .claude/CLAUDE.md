## Session rules

- Build in the order of section 15 of the spec. Commit after each phase.
- Track progress in docs/RELEASE.md. Update it after every phase with evidence.
- On resume: read docs/RELEASE.md and `git log`, then continue from the next unfinished step in section 15.
- Never write secrets to any file in the repo. Real values go in .env, which is gitignored.
- Never invent data. Unverifiable records go to DATA_TODO.md.
- User-facing strings in Romanian. Code, comments, and commits in English.
